# runtime contract checklist

## 目的

- runtime / structure 依存変更時の最低限の確認順を固定する。

## checklist

1. `project-truth-core.md` と `HAUB` を確認したか
2. design contract を確認したか
3. inventory を確認したか
4. handoff matrix があるか
5. contract probe があるか
6. 関連 unittest があるか
7. path read/write の old/new が整理できているか
8. artifact producer/consumer の変更が整理できているか
9. directory structure の変更が rule と矛盾していないか
