# Session Handover Writer

session 間の連続性を保つために使う。

## 出力 section
1. 決定事項
2. 未解決事項
3. 次 action
4. risk / assumption

## 規則
- 各 entry は短く、行動につながる形で書く。
- 可能な限り file 参照付きの evidence を優先する。
